# Home FortG · Proposta de interface

Implementação front-end de uma proposta de página para a **FortG**, marca própria da Loja do Mecânico.

Desenvolvi a interface a partir do design de um profissional de UX/UI da squad de front-end. **O projeto não chegou a ser publicado** e ficou incompleto. Este repositório preserva a implementação como registro de aprendizado e experiência.

## Minha participação

- Transformação do layout fornecido em HTML e CSS.
- Configuração de carrosséis com Tiny Slider.
- Implementação de menus e dropdowns.
- Adaptação de um script em jQuery para o menu hambúrguer em dispositivos móveis.
- Ajustes de apresentação para diferentes larguras de tela.

O desenvolvimento front-end é de minha autoria; a criação do design pertence ao profissional de UX/UI que forneceu o layout.

## O que está no repositório

- Página `fortg-home-local.html`, com estilos e scripts próprios no mesmo arquivo.
- Arquivos locais de Bootstrap CSS e jQuery.
- Imagens utilizadas nos banners, cards, ícones e demais seções.
- Referências externas a fontes, Bootstrap JavaScript e Tiny Slider.

O contexto original menciona trabalho em outras partes da proposta. O arquivo HTML disponível neste repositório é a implementação da home; não é apresentado como um site completo.

## Tecnologias

HTML, CSS, JavaScript, Bootstrap, jQuery e Tiny Slider.

## Como visualizar

```sh
git clone https://github.com/guarinFE/Home-FortG-LDM.git
cd Home-FortG-LDM
```

Abra `fortg-home-local.html` no navegador, mantendo os arquivos da pasta juntos para preservar os caminhos das imagens e das bibliotecas locais. Não há instalação de pacotes nem etapa de build.

Com Python instalado, também é possível iniciar um servidor local:

```sh
python -m http.server 8000
```

Acesse `http://localhost:8000/fortg-home-local.html`.

## Estado da proposta

- Projeto não publicado e incompleto.
- Há links sem destino definido ou apontando para `#`.
- Os campos de busca e cadastro fazem parte da interface; o código disponível não implementa envio de cadastro nem pesquisa de produtos.
- Parte dos recursos é carregada de CDNs e de endereços externos, exigindo internet para a visualização correspondente.

Essas características fazem parte do estado preservado da proposta. O repositório não representa uma loja virtual funcional nem comprova resultados comerciais.
